# Security Policy

## Supported Versions

Currently, active security patches are provided only for the versions listed below.

| Version | Supported |
| --- | --- |
| v2.x | :white_check_mark: Supported |
| < v2.0 | :x: Not Supported |

## Reporting a Vulnerability

If you discover a security vulnerability in the ScriptRowberry compiler or the web playground, please do not create a public GitHub issue. Instead, report it privately following these steps:

1.  Draft a detailed description of the vulnerability, reproduction steps, and attach a minimal test case (.scrb).
2.  Send the details to the project maintainer at [lemon.pai6784@gmail.com](mailto:lemon.pai6784@gmail.com).
3.  We will respond within 3 business days of receipt. We request that you keep the vulnerability details private until a fix is released.
